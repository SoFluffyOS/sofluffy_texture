# Changelog

## 0.1.0

- 🍎 **macOS**: IOSurfaces and CVPixelBuffers as a Flutter texture, as a set or one buffer per frame.
- 🪟 **Windows**: shared D3D11 textures as a Flutter texture.
- 🐧 **Linux**: dmabufs as a Flutter texture, with native fences.
- 📦 **`GpuTextureView`**: shows the texture at the buffers' aspect ratio.
